# All Video Downloader

تطبيق Android أصلي بـ Kotlin وJetpack Compose وMaterial 3 لتنزيل الوسائط المسموح بها من الروابط المدعومة بواسطة yt-dlp، مع اختيار الجودة، استخراج الصوت، إشعارات تقدم، وحفظ آمن عبر MediaStore.

## المزايا

- تحليل روابط YouTube وFacebook وInstagram وX/Twitter وTikTok وغيرها محليًا على الجهاز.
- اختيار الجودة/التنسيق أو استخراج MP3.
- تنزيل مستمر عبر WorkManager وإشعار تقدم وانتهاء أو فشل.
- حفظ الفيديو في `Movies/All Video Downloader` والصوت في `Music/All Video Downloader`.
- لا يطلب أي صلاحية تخزين أو `MANAGE_EXTERNAL_STORAGE`؛ يستخدم MediaStore للحفظ فقط.
- استقبال الروابط من قائمة مشاركة Android.
- واجهة Material 3 ديناميكية ووضع ليلي تلقائي.

## البناء

افتح المشروع في أحدث Android Studio، ثبّت Android SDK 37، ثم Sync وRun. يعتمد المشروع على `youtubedl-android` 0.18.1، ولذلك يخضع المشروع لترخيص GPL-3.0.

## حدود مهمة

دعم المنصات ليس مضمونًا دائمًا لأن المواقع تغيّر آلياتها باستمرار، وبعض الروابط الخاصة تحتاج ملفات Cookies يملكها المستخدم. لا يتجاوز التطبيق DRM، ويجب استخدامه فقط للمحتوى المملوك للمستخدم أو الذي يسمح صاحب الحقوق والمنصة بتنزيله.
